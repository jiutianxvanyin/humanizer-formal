# 学术文体

配合 `SKILL.md` 使用。适用于论文、学位论文、文献综述、研究报告、
会议摘要、开题报告。

## 语域锚点

学术写作有两个层级，选错会出问题：

| | 本科教科书（L3） | 研究生专著（L1） |
|---|---|---|
| 句长均值 | 24.2 – 30.3 词 | 37.2 词 |
| p90/p50 | 1.85 – 2.05 | 2.27 |
| 长句（>50 词）占比 | 4.8% – 6.2% | 19.4% |
| 名词化 | 34.8 – 38.6 | 50.0 |
| 抽象名词 | 0.09 – 0.32 | 1.16 |
| 认知限定 | 4.03 – 4.58 | 1.55 |
| 含数字句占比 | 0.30 – 0.35 | 0.54 |

投期刊走 L1，写综述或面向跨学科读者走 L2，教学材料和科普走 L3。

**“从论文腔降到教科书用语”在这张表上的具体含义**：句长砍约三成，
长句占比从 19% 降到 6%，名词化从 50 降到 37，抽象名词砍到四分之一。
句子变短、词变常见，但**不引入任何口语成分**。

有意思的一点：研究生专著的认知限定（1.55）比本科教科书（4.03–4.58）
**低得多**。因为形式化建模类专著给的是定理和推导，不需要软化；
教科书要向初学者交代边界条件。所以限定语密度不是“越学术越高”，
而是取决于**论证类型**。

## 结构

### IMRaD

引言（Introduction）、方法（Methods）、结果（Results）、讨论（Discussion）。

各部分的时态和语态惯例不同，不要统一化：

- 方法用过去时，被动语态是规范（`Samples were collected`），
  不要为了“更主动”改掉
- 结果用过去时陈述发现
- 讨论用现在时讨论含义

### 引言的 CARS 模型

Swales 的 Create A Research Space 模型，三步：

1. **建立研究领域**：说明这个问题为什么重要（一到两句，不要写成综述）
2. **指出空白**：已有研究做到哪里，缺什么
3. **占位**：本文做什么，怎么做，得到什么

AI 写引言的典型问题是**第一步写太长、第二步含糊、第三步不具体**。
空白必须指名道姓（哪项研究、缺哪个条件），不能只说“相关研究尚不充分”。

### 摘要

结构化摘要四要素：目的、方法、结果（含关键数字）、结论。

不要写“本文对……进行了研究”这类元描述，直接给内容。中文摘要尤其容易
写成公文腔，注意避免。

## 元话语校准

依据 Hyland 的元话语分类法。学术写作的元话语不是冗余，是功能性的，
但需要校准而非削减。

### 六类元话语

| 类别 | 功能 | 例 |
|---|---|---|
| 限定语 hedge | 降低断言强度 | may、suggest、可能、倾向于 |
| 增强语 booster | 提高断言强度 | clearly、demonstrate、显著、充分 |
| 态度标记 | 表达评价 | surprisingly、值得关注 |
| 参与标记 | 拉入读者 | consider、note that |
| 过渡标记 | 逻辑衔接 | however、因此 |
| 证据标记 | 标注来源 | according to、据 |

### 校准原则

**限定强度必须与证据强度相称。** 这是整个学术文体部分最重要的一条。

- 有实验或统计支撑 → 直接陈述
- 有相关性无因果识别 → 说“同期发生”“相关”，不说“导致”
- 只有理论推断 → 明确标注为推断
- 证据不足 → 说清楚缺什么，不要用软词糊过去

> 改前：数据可能表明该机制或许在一定程度上有所作用，这似乎倾向于
> 支持我们的假设。
>
> 改后：处理组的成本比对照组低 26%（p < 0.01）。该差异与我们的假设方向
> 一致，但样本仅覆盖两个行业，外部效度有限。

第二种写法**信息量更大而且更诚实**，它同时给出了强结论和明确的边界。
无差别 hedging 的问题不是太谦虚，是**没有传递任何关于确定性的信息**。

### 中英差异必须分开处理

| | 认知限定密度 |
|---|---|
| 英文学术 | 4.03 – 4.58 |
| 中文学术与机构文本 | 0.29 – 0.91 |

差一个量级。这不是哪种语言更严谨，是两种语言的学术规范不同：英文靠
显式限定词标注确定性，中文更多靠句式和语序。

**互译时限定密度必须重设，不能照搬。** 英文的 4.5 搬进中文会显得畏缩，
中文的 0.5 搬进英文会显得武断。机器翻译在这一点上几乎总是照搬，
是最容易识别的痕迹之一。

同样地，中文的连接词密度（人写 0.57 – 2.06）远低于英文，译入中文时
原文的连接词大约要删掉一半。

## 引用与可核查性

### 硬规则

- **不要编造文献、DOI、页码、期刊名。** 这是学术写作里最严重的错误。
- 「研究表明」必须有具体出处，否则删掉这个说法
- 原文没有出处就**标注缺失**，不要补一个看起来合理的
- 转述他人观点要能追到原文，不要转述转述

### 提醒使用者核对

AI 生成的引用有编造风险。改写学术文本时，如果发现引用信息不完整或
可疑，**明确标注出来提醒作者核对**，不要静默补全，也不要静默删除。

## 术语一致性

学术写作要求术语**一字不变地复现**。「用户留存率」不能中途变成
「客户黏性」，`working memory` 不能中途变成 `short-term memory`。

这和通用写作建议里的“避免重复用词”直接冲突。学术语境下**一致性优先**。

首次出现给定义，之后一律用同一表述。缩写首现给全称，之后一律用缩写。

## 中文学术文本的额外注意

中文学术写作容易混入两种不合语域的成分：

**公文腔**：高质量发展、深入推进、切实加强、有力支撑。这类词在政策
文本里正常，在学术论文里是语域错位。实测中文政府白皮书的增强语密度
是 8.35，教科书只有 0.51–0.94，差一个量级。

**翻译腔**：见 `patterns-zh.md` 的 A 族。中文学术文本大量译自英文
文献，翻译腔渗透严重。重点检查连接词过密、「的」字堆叠、「被」字滥用、
轻动词结构这四项。

## 不要做的事

- 不要为了“更学术”而增加名词化和抽象名词。那是提高语域，不是提高质量。
- 不要削减有证据支撑的限定语。学术写作中恰当的 hedging 是义务。
- 不要把方法学章节的被动语态改成主动。那是规范。
- 不要动数字、单位、统计量、样本量和显著性水平。
- 不要因为某段“读起来像 AI”就改写它。先判断是 A 族问题（机器痕迹）
  还是 B 族问题（语域不符），两者处理方式相反。
